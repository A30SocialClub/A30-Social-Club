# A30 Social Club Website

A simple, responsive A30 Social Club website designed around the club's terracotta, cream, editorial aesthetic.

## Files

- `index.html` — site content
- `styles.css` — responsive styling
- `assets/a30-logo.png` — A30 logo
- `assets/science-on-the-rocks.jpg` — event flyer
- `assets/salsa-bachata.jpg` — event flyer

## Publish

This site is designed for GitHub Pages. Create a public repository and upload these files to the repository root, then enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).
